# Security policy

This is a learning demo. It is not hardened for production. The CA hands out private keys without authentication, so do not run it on a network you do not trust. See the "Known limits" section of the [README](README.md).

## Report a vulnerability

The project has no private reporting channel or response time. Open a GitHub issue. Do not include secrets, credentials or personal data. Include the steps to reproduce, the commit you tested and what an attacker gains.

## Supported versions

Only the latest commit on `main` is supported. There are no tagged releases.
